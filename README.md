# Recipe Finder App

A modern web application for discovering and saving your favorite recipes. Built with HTML, CSS, and JavaScript, this app provides a seamless experience for finding, viewing, and managing recipes.

## Features

### Search & Discovery
- 🔍 Instant recipe search
- 📜 Search history with click-to-reuse functionality
- 🎯 Category and filter options
- 🎲 Random recipe suggestions
- 🌟 Featured recipes section

### Recipe Management
- 📋 Detailed recipe view with ingredients and instructions
- ⭐ Favorite recipes system
- 📱 Responsive design for all devices
- 🌙 Dark mode support
- 🔄 Real-time updates

### User Experience
- 🎨 Modern glassmorphism design
- ⚡ Smooth animations and transitions
- 📝 Clear error messages and notifications
- 🔝 Back to top button
- 🖼️ Image loading animations

## How to Use

1. **Searching Recipes**
   - Enter a search term in the search bar
   - Use filters to narrow down results
   - Click on a recipe card to view details

2. **Managing Favorites**
   - Click the heart icon in recipe details to add/remove favorites
   - Access favorites through the navigation menu
   - Remove favorites directly from the favorites page

3. **Using Search History**
   - Click the search input to view recent searches
   - Click on a history item to reuse the search
   - Clear history using the clear button

4. **Dark Mode**
   - Toggle dark mode using the sun/moon icon
   - Settings persist between sessions

## Technical Details

- **API Integration**: Uses TheMealDB API for recipe data
- **Local Storage**: Saves favorites and search history
- **Responsive Design**: Works on mobile, tablet, and desktop
- **Modern UI**: Glassmorphism design with smooth animations

## Installation

1. Clone the repository
2. Open `index.html` in your browser
3. No additional setup required
